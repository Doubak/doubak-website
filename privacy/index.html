隐私政策

一句话：豆备不收集任何数据，因为它没有地方可收。 没有服务器，没有账号，没有统计脚本，没有 cookie。

最后更新：2026-08-09 · 适用于浏览器扩展「豆备 Doubak」与本站 doubak.com

这个扩展会碰到什么

为了把你的豆瓣内容备份下来，扩展会在你自己的浏览器里读取这些东西：

它读什么存到哪儿会不会离开你的设备
你的豆瓣页面（标记、短评、广播、日记、图片等） 浏览器本地存储（OPFS），以及你自己选的文件夹 不会
你的豆瓣登录状态 哪儿都不存 —— 它用的是浏览器已有的 cookie 不会
抓取进度与断点 浏览器本地（IndexedDB） 不会

扩展只向 douban.com 与 doubanio.com 发请求 —— 也就是你本来就在访问的那个网站。除此之外它不连接任何第三方， 包括本站：安装之后 doubak.com 挂掉也不影响它工作。

明确没有的东西

  • 没有服务器。这个项目没有后端，也就没有任何地方能接收你的数据。
  • 没有账号、没有登录。扩展本身不需要你注册任何东西。
  • 没有统计与遥测。不上报使用情况、不上报崩溃、不做 A/B。
  • 没有第三方代码。零运行时依赖，没有 CDN、没有分析脚本、没有广告。
  • 不出售、不共享、不用于训练。没有数据到手，也就无从谈起。
  • 本站不设 cookie，也不加载任何第三方资源。

为什么可以不只是相信这段话。 扩展的全部源码是公开的，权限清单逐条写了理由，而且它声明的网络权限 只包含 https://*.douban.com/* 与 https://*.doubanio.com/* —— 浏览器不会允许它连接别处。 安装时的权限警告就是这份承诺的技术兑现。

数据在你手里，也由你负责

备份下来的档案是你的文件。豆备把它写到你指定的文件夹之后就不再管它 —— 我们既看不到它，也删不掉它。相应地：

  • 删除：删掉那些文件即可；扩展内的副本可以在「存储」页删除。卸载扩展会连同浏览器里的存储一起清掉。
  • 导出：档案是标准 WARC 加 JSON 索引，用 jq、pywb、ReplayWeb.page 都能直接打开，不依赖本工具。
  • 如果你把生成的站点公开发布：那是你的主动行为。发布前请自己确认里面没有你不想公开的内容 —— 短评、日记与广播里可能包含个人信息。

关于别人的数据

豆备刻意不抓第三方内容：别人在你广播下的回复、你的关注与被关注列表、 豆邮、别人上传的图片，都不在抓取范围内。这既是隐私边界，也是一条工程边界。 详见首页的「它刻意不抓什么」。

即便如此，你自己写的内容里仍然可能提到别人。这一点在你决定是否公开发布时需要自己判断。

变更与联系

这份政策如有变更，会更新本页顶部的日期，并记录在 Git 提交历史里 —— 改了什么、什么时候改的，都可以自己核对。
